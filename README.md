Даг csv_to_postgresql выполняет загрузку данных в таблицы rd.deal_info и rd.product
В качестве стратегии загрузки была выбрана insert...if not exists, так как в задании было указано, что необходимо вставить отсутствующие записи
В качестве столбцов, идентифицирующих записи, были определены столбцы ("deal_rk", "effective_from_date") для deal_info и ("product_rk", "effective_from_date") для product соответственно

Процедура refresh_loan_holiday_info() загружает данные в витрину данных. 
Выполняется полная загрузка данных, так как: необходимо не только добавить новые строки, но и обновить существующие
